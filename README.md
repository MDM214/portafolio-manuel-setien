# Portafolio profesional de Manuel Setién Joya

Portafolio web personal creado para presentar mi perfil profesional, mis conocimientos técnicos y los proyectos desarrollados durante mi formación y evolución como desarrollador de software.

## Sobre mí

Soy técnico informático y desarrollador de aplicaciones multiplataforma, con experiencia en soporte a usuarios, diagnóstico y reparación de equipos, redes, TPV y asistencia técnica a empresas.

Tras completar mi formación en Desarrollo de Aplicaciones Multiplataforma, he orientado mi trayectoria hacia el desarrollo de software, especialmente en Java, Spring Boot, Android y desarrollo web.

## Estado del portafolio

Primera versión funcional desarrollada y probada localmente.

El portafolio se actualizará a medida que los siguientes proyectos alcancen una versión estable, documentada y publicable.

## Proyectos

### 1. TaskManager API

API REST desarrollada con Java y Spring Boot para la gestión de usuarios y tareas.

Características principales:

- Autenticación mediante JWT.
- Autorización y control de acceso.
- Validación de datos.
- Gestión global de excepciones.
- Persistencia mediante MariaDB.
- Documentación con Swagger/OpenAPI.
- Pruebas automatizadas.
- Análisis de cobertura mediante JaCoCo.
- Control de versiones con Git y GitHub.
- Primera versión estable `v1.0.0`.

Repositorio:

https://github.com/MDM214/taskmanager-api

Estado: finalizado.

### 2. Cliente Android

Aplicación Android destinada a consumir TaskManager API y permitir la autenticación de usuarios y la gestión de tareas desde dispositivos móviles.

Estado: en desarrollo.

### 3. Gestor de tareas Java

Aplicación desarrollada en Java para demostrar programación orientada a objetos, organización modular, tratamiento de datos y persistencia.

Estado: próximamente.

### 4. Tic&Tac 3.0

Actualización profesional del proyecto web Tic&Tac, con una nueva identidad visual, diseño adaptable y mejoras de experiencia de usuario.

Estado: próximamente.
